# 3. Known Issues

There are a few known issues with fp without an easy fix:

* When using the automatic timer, riding Lakilester or Sushie counts as one long cutscene. This means things that would normally increment the cutscene counter, such as going through a loading zone, no longer will.
* In rare circumstances when using the free camera, the game may crash.
* Entering the hub room just past the first Bowser door in Bowser's Castle after loading a save file from anywhere other than the game's main menu will cause the game to crash on some flash carts.
* Some SD cards don't seem to work on Wii VC.
